# 截图

README 首页打算放两张图，放在 `assets/screenshots/`：

1. `chat.png` —— 私聊窗口，几轮正常对话。
2. `status.png` —— 状态中心窗口，「聊天程序」和「QQ 接入」都是正常状态。

截图建议：

- 宽度 800–1200 px，PNG，别用 webp。
- 用 Windows 的 `Win + Shift + S` 截窗口，别截整个桌面。
- 把 QQ 号、群号、好友昵称、头像打码。
- 别把 API Key、cookie、日志里的路径截进去。

放好之后，把 README 开头那段注释里的两行 `![...]` 取消注释，提交时把图片一起带上。

如果暂时没有图，就别取消注释——空图片比没有图更难看。
